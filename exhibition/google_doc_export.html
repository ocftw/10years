一、策展展論

主標：科技征途：無硝煙的自由戰
副標：開源運動在臺灣｜OCF 十週年特展

——打破科技與軟體封建，一場令人熱血沸騰的開放世界冒險——

1989——一個象徵自由的年代，處處都在為破除集權和獨裁，鳴響關鍵一槍。
現實的另一端，虛擬的網路軟體世界，也在打破壟斷、封閉的生態，爭取自由開放，揮起革命大旗。

在這個實體 MMORPG 遊戲中，你將化身為「開源人」，踏遍臺灣的雲端伺服器，展開一場場打怪任務，逐步攻克傳統商業軟體和閉源軟體的堡壘，開拓自由世界的疆域。開源人們穿梭於現實與虛擬，不斷迎接封建傳統的異世界挑戰；但他們無所畏懼，無論單打獨鬥或團隊行動，為了推動軟體技術和網路的開放普及，創造自由的未來而拚搏。

隨著遊戲進展，你將走入「開源運動在臺灣」的輝煌歷程，見證無數勇敢的開源人，如同冒險者越洋取經，完成全球各地推廣開源的游擊任務，並像遊戲中的公會與結盟般，在臺灣組建起一個個活躍的開放科技社群，共同成就今天的開源環境。

有人在前線奮戰，總有人要幫補——開放文化基金會自 2014 年起正式擔任補師角色，承載開源社群的期待和共識，化為推動開放精神的幕後舵手。十年間，基金會支持社群的壯大發展，在各界發揚開源精神，作為臺灣開源人的前鋒與後盾，攜手走過無數風雨，逼退封閉勢力，讓「開放」在臺灣生根蓬勃。

開源人們也逐漸意識到，開放科技已不僅僅是必需的基礎設施，更是資通訊產業的推動力。冒險者們竭力於影響社會環境——這個從游牧到很多聚集發生的「臺北」，至今也從王國 NPC 手中，獲取各種城市運作的儀表板技術文件及原始碼，邀請更多不同的可以以自由開放精神，也打造出屬於自己的智慧城市。這場遊戲正在持續更新，為玩家們帶來更加自由無垠的虛擬世界。

現在，歡迎走進「科技征途：無硝煙的自由戰．開源運動在臺灣｜OCF 十週年特展」，在「社群回憶錄：開源運動在臺灣」中，邀請每個參觀者，和我們一同以行動策展的方式，共同探索「開源人」們在臺灣和世界各地的精彩故事，同時也歡迎貢獻你知道的記憶篇章；到「開源繁星錄」中，一窺來自過去、未來與遠方，自由星空下的里程碑和 OCF 的祝願。也別忘了走到木棧板區「社群公會大廳」參觀，一睹絕版 SSS 開源實體寶物和道具的真容！同時，別忘了展區之中還有許多板子加入我們，成為這場開源革命的一部分，開啟你的科技歷險！

本展所提及之「開源軟體」，為「自由與開放原始碼軟體」之統稱，泛指採用經自由軟體基金會或開放源碼促進會所認可的授權條款釋出，以供大眾自由利用的軟體或科技。

社群是一群有共同興趣和志向，聚在一起實體或網路上討論的人們。社群的討論主題多元且具遊牧的特性，常見的方式是透過網路討論議題、咖啡店內小聚會，大活動（CON）則是社群的大型見面會。

無論是公民科技或是開源社群，重要記憶眾多且本展篇幅有限，無法涵蓋所有事件，在此特別說明。歡迎在現場的你，發揮開源與自由貢獻精神，透過我們的互動方式，貢獻你知道的社群和記憶哦！

開放文化基金會（Open Culture Foundation, OCF）

開放文化基金會（Open Culture Foundation, OCF）是一個非營利性組織。透過推廣開放科技和跨界合作，在臺灣持續的銜繫科技社群與其他公／私領域，來保障開放共創的數位人權、支持透明涵融的數位公民社會。

所謂開放科技，是開放源碼、開放資料及開放政府三個概念的集合，指數位世界的建構、資料收集及政府治理皆以公開、透明及眾人參與的方式執行，能更有效地促進數位人權和網路自由的落實，進而達到數位公民社會的實現。

自 2014 年創立以來，OCF 以法人做為組織形式，支持臺灣 40 多個開放科技社群，在過程中，不僅是持續性的推廣開放科技概念，OCF 也開始參與政策倡議，為眾人的數位人權發聲，進而創建出在臺灣發展開放科技的基地。然而，這些成果並非由開放文化基金會獨立實現，而是透過科技社群和公民夥伴一起促使臺灣的數位／網路環境變得更加公開、透明，利於公眾參與。

1983

牛羚的咆哮：開放原始碼的銀河革命

自由軟體運動的起源。GNU 計畫的目的是開發一個完全由自由軟體組成的作業系統，產出眾多重要的軟體，並與後來出現的 Linux 核心一起成為現今多數作業系統的基礎。

小知識：GNU 是「GNU is Not Unix」的縮寫。GNU 計畫的目標是開發出與 Unix 系統相容，但不受商業公司限制的作業系統。而牛羚（Gnu，一種非洲羚羊）也成為自由軟體運動的代表動物。

1985

締結自由之約：星際四大自由

自由軟體基金會成立。提出自由軟體的四大自由定義：使用、研究、修改、散布，並持續推廣 GNU 計畫。

小知識：自由軟體（Free Software）中的「Free」常常被誤指為免費，但它的含義是言論自由，而不是免費的啤酒「Free as in speech, not free as in beer」。

1989

數位魔法寶典：GPL 授權條款的未來法典

GPL 授權條款發布。其被廣泛使用於 GNU 計畫的專案，它將法律文字簡單化，以授權條款保障使用者能自由使用及修改軟體，並規定修改後的作品，以同樣的授權方式傳播下去。

小知識：授權條款是自由或開源軟體的必備條件，軟體著作人透過這些條款，釋出部分權利，讓其他人能自由合法地使用和再散布軟體，從而促進快速發展和共享知識的精神。

（時間說明欄：1991 - 臺灣）

開源萌芽：始於 Linux 使用群的冒險者逐步鏈結

在網路撥接速度如牛行步的年代，臺灣逐漸接軌國際，存取全球開源資源。隨著 Linux 的出現，開源運動的先驅者們通過 BBS 站、NewsGroup 和文字介面的 IRC 等工具，進行技術交流和知識共享。這些努力讓開源的種子在校園、生活和職場中悄然生根，串聯起對開放原始碼有熱情的人們，逐步形成開源運動的網絡。

1991

Linux 核心：開放宇宙的萬獸之源

Linux 核心誕生。因採 GPL 授權讓大眾自由利用，以 Linux 為核心的知名作業系統如 Debian、Fedora 等相繼出現，開啟開源作業系統的新時代。

小知識：核心的作用是將應用程式所發出的要求，轉譯為中央處理器能執行的指令。

小知識：Tux 這隻企鵝代表了 Linux，如同 GNU 的牛羚，自由軟體都喜歡用各種動物來作為代表吉祥物。

1997

《教堂與市集》：軟體開發新手的未來哲學寶典

在《教堂與市集》這本書中，將傳統軟體開發比喻為封閉的教堂模式；開放原始碼則像開放的市集。作者比較兩者的差異，鼓勵軟體開發應該有廣泛的參與和透明公開的協作方式。

小知識：書中以「Given enough eyeballs, all bugs are shallow」總結開放原始碼的精神。意思是只要有夠多人檢視原始碼，程式臭蟲（bugs）最終都會被發現並修正。亦即參與開發的人越多，軟體的除錯和開發過程就會越迅速。

（時間說明欄：1997 - 臺灣）

網路浪潮：從繁榮到挑戰

網際網路的發展如脈動推進世界。Linux 基於 Apache 網頁伺服器崛起，正值 .com 網路熱潮，使其成為網路基礎建設核心，也逐漸成為產業界的明星，促使開源成為不可忽視的力量。然而，隨著網路泡沫化，臺灣面臨國際智慧財產制裁和成大 MP3 搜查事件等挑戰。智慧財產權日益嚴格，艱難的國際局面迫使政府重視開源，國家級計畫和教育部計畫接連推出，為臺灣開源社群奠定了下一個十年的基礎。在這段發展與挑戰共存的時期，臺灣開源運動經歷風雨洗禮，最終屹立不搖，繼續向前邁進。

開源異世界的時光穿梭器：Git 的初次星際登場

分散式版本控制系統 Git 發布，用於管理軟體開發過程的程式碼版本。Git 的分散式架構，使得開發者可以在各地更方便地協作和貢獻程式碼，而不容易和其它開發者產生程式碼的互相干擾和衝突。

小知識：版本控制是開源世界中很重要的概念與工具，簡單說就是畫圖畫到一半出錯了，要回到上一步或是上上步的動作。而分散式版本控制系統的出現，解決了以往集中式版本控制系統的不足，是軟體開發協作的重要的里程碑。

2024

王國的夥伴們，加入冒險者行列！

OCF 與數位發展部合作，促使政府採購落實「使用公共款應公開原始碼」（Public Money, Public Code，PMPC），實踐科技開放，進而活絡民間與產業利用，達成政府的透明與責信，實踐數位民主的精神。

小知識：PMPC（Public Money Public Code）意即政府使用民脂民膏所採購的數位系統，應該以開放原始碼的方式，讓程式碼自由被民眾所利用。歐洲已行之有年，而臺灣自從數位發展部成立之後，開始進行 PMPC 的推動，OCF 協助初期的中文化與產官學三方的協商工作。

回顧開源世界的發展歷程，最初的開源軟體隨著學術研究的自由精神在軟體實驗室和研究機構中迅速成長。然而，當微軟創辦人比爾·蓋茲因不滿軟體被無償複製，發表了著名的「致愛好者的公開信」，呼籲保護軟體著作權後，軟體開發的主流逐漸轉向封閉。儘管如此，開源社群始終堅守「自由與分享」的理念，並明確定義開源精神，讓協力與開放文化，打破閉鎖的主流，驅動商業與科技的發展。

進入 2000 年後，隨著數位技術與現實生活逐漸融合，人與人工智慧共存的智慧城市開始崛起，開源精神也逐步滲透到生活和市政的各個層面。然而，面對 2024 年的 AI 浪潮，新興科技帶來的挑戰也日益嚴峻，人工智慧的開源與封閉之爭持續升溫。天下無難事，只因天下還有「開源人」。開源的冒險者們那份對開放與自由的堅持，將繼續突破重重難關，引領科技的未來。
